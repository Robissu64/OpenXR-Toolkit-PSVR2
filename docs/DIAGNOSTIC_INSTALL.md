# Arquivo histórico: instalação da build de diagnóstico

As instruções desta fase foram substituídas pelo [guia de instalação da RC1](PSVR2_RC1_README.md). Para uma instalação atual, use o artifact `OpenXR-Toolkit-PSVR2-RC1-x64` e confira `BUILD_COMMIT.txt`.

Os logs da RC1 mantêm `[PSVR2-DIAG]` para lifecycle e falhas de Eye Tracking e `[FOV-CROP]` para calibração, resolução e aceitação da recomendação. As amostras periódicas de frame, sync, pose e projected gaze da fase de diagnóstico foram removidas.
